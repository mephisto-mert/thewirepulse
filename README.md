> Built as the official digital broadcast web companion for **[@thewirepulse](https://www.instagram.com/thewirepulse/)**.

---

## ⚡ Features

- 📰 **1-10 Dynamic Headline Carousel:** Real-time breaking carousel featuring auto-play, timer bar, category badges, and keyboard navigation.
- 🔴 **Live Ticker Ribbon:** Continuous streaming agency wire updates with sub-minute latency indicators.
- 🧭 **Editorial Taxonomy:** Dedicated desks for *World Affairs*, *Defense & Conflict*, *Global Markets*, *AI & Technology*, and *Diplomacy*.
- 📖 **Immersive Full-Screen Reader:** Deep editorial article viewer with original agency citations and related wire stories.
- 🔖 **Client-Side Bookmarking & Sharing:** Instant clipboard link propagation and reading list persistence.
- 🌓 **OLED-Tuned Broadcast Aesthetic:** Sleek ultra-dark typography (`Plus Jakarta Sans` & `JetBrains Mono`) with subtle depth blur.
- 📱 **100% Mobile & Desktop Responsive:** Fluid touch controls and adaptive viewport scaling.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Styling:** Tailwind CSS + PostCSS + CSS Variables
- **Icons:** Lucide React
- **Feeds Engine:** Fast XML RSS streaming parser across Reuters, BBC News, Deutsche Welle, France 24, and Al Jazeera
- **Deployment:** Vercel Edge Network / Standalone Node.js

---

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/mephisto-mert/thewirepulse.git
cd thewirepulse

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` to inspect the portal.
